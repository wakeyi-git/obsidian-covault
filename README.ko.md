# CoVault for Obsidian

> [English](README.md) · **한국어**

운영자용 vault의 **구성원별 폴더**와 **구성원 개인 vault**를 양방향으로 동기화하는 Obsidian 플러그인입니다.
중앙 서버로 **CouchDB**(시놀로지 NAS 등 자가 호스팅)를 사용하고, 클라이언트는 **PouchDB**로 구현합니다.

```
ManagerVault/
├─ 구성원A/  ⇄  mirror_member_a  ⇄  구성원A Vault/
├─ 구성원B/  ⇄  mirror_member_b  ⇄  구성원B Vault/
└─ 구성원C/  ⇄  mirror_member_c  ⇄  구성원C Vault/
```

하나의 플러그인을 배포하고, 최초 실행 시 **구성원 모드** 또는 **운영자 모드** 역할을 선택합니다.
구성원은 자기 vault에서 평소처럼 노트를 작성하고, 운영자는 하나의 vault에서 구성원별 폴더를 관리합니다.

핵심 특징:
- **오프라인 우선** — 로컬 PouchDB ↔ 원격 CouchDB live replication. 끊겨도 큐에 쌓였다 재연결 시 전파.
- **QR/코드 초대** — 운영자가 구성원을 초대하면 구성원은 admin 자격증명 없이 **자기 mirror DB만 접근**하는 최소 권한 계정으로 자동 설정. 초대가 유출되면 운영자가 **'비밀번호 재발급'** 으로 이전 초대를 즉시 무효화.
- **서버 강제 격리** — 구성원별 데이터는 CouchDB 데이터베이스별 권한(`_security`)으로 서버에서 격리.
- **마크다운 + 첨부파일** — 노트뿐 아니라 이미지·PDF 등 첨부도 동기화(PouchDB attachment).
- **충돌 보존** — 양쪽 동시 편집 시 로컬을 지키고 충돌 해소 UI로 비교/선택. 마크다운·첨부 모두 원격본을 `_충돌/`에 보존.
- **공동 폴더** — 모둠/워크스페이스가 한 폴더를 공유(전용 DB + 멤버 권한), 운영자 배포로 구성원에게 자동 전파.
- **실시간 공동 편집** — 공동 폴더 문서를 Yjs로 글자 단위 동시 편집. **마크다운·Excalidraw 모두** 커서·이름 + **참가자 칩**(우하단 상시 표시)으로 마우스를 안 쓰는 태블릿·모바일에서도 누가 함께 편집 중인지 보입니다(이미지 동기화, Excalidraw 플러그인 필요). 별도 WebSocket 서버 필요.
- **실시간 제어·접근** — 전용 **실시간 탭**에서 라이브 편집을 관리합니다: 사용 토글, **파일별 참여자 지정**(지정한 구성원만 그 노트를 공동 편집, 나머지는 일반 파일 동기화), 선택형 **공유 파일 읽기 전용** 정책(구성원은 그 노트가 자신에게 활성 실시간 세션일 때만 편집 가능), 실시간 **활성 세션 목록**(지정 파일을 클릭 한 번에 열기 — 닫아도 목록 유지). 구성원을 파일에서 빼면 그 구성원의 라이브 세션이 즉시 종료됩니다.
- **실시간 보안** — 실시간 토큰을 **공동 공간별 HMAC 서명 토큰**으로 발급해, 한 토큰이 유출돼도 **그 공간 room에만** 접근(워크스페이스 전체 X). 서버는 placeholder 시크릿이면 기동을 거부하고, 운영자의 토큰·시크릿은 **Obsidian Secret Storage**에 보관(`data.json` 평문 아님).
- **메신저** — 내장 **대화 탭**: **학급 전체 채널**(학급 공유 DB)과 **1:1 DM**(운영자↔구성원, 개인 mirror DB 경유). 텍스트, **`[[위키링크]]`(옵시디언식 자동완성)**, URL, **파일·이미지 첨부**(파일을 상대에게 복사)를 보낼 수 있고 링크·이미지 미리보기가 인라인으로 렌더됩니다. 보낸 사람은 ID가 아니라 이름으로 표시됩니다.
- **피드백 레이어** — 본문을 고치지 않고 텍스트에 앵커를 단 댓글로 의견 전달(공유·개인 노트 모두). 운영자는 **전체 미해결 피드백함**으로 흩어진 피드백을 한 번에 확인. 세션 중 주기적 스냅샷도 지원.
- **학급 대시보드** — 자동 프로비저닝되는 **학급(homeroom) 공동 공간** 위에 올린 선택형 운영자↔구성원 작업 공간: **알림장**(읽음 확인 + 학급 댓글 + 비공개 질문/답글), **주간 시간표 + 수업 안내**, **과제**(배포 → 버전 스냅샷 제출 → 점수/루브릭/총평 채점 → 반환), **체크리스트/루틴**, **통계**(읽음·제출·점수·완료율, CSV 내보내기). 알림장·수업은 **옵시디언 편집창에서 프론트매터로 작성**(초안 → 게시 토글)하고, 알림장·수업·과제는 **재사용 콘텐츠 템플릿**을 지원합니다.
- **운영 UX** — 운영자 **온보딩 마법사**(‘시작하기’ 체크리스트), **구성원 명단 일괄 추가**(구성원별 폴더 선택 가능한 명단 붙여넣기) + 미초대 구성원 **일괄 초대**, **배포 미리보기(dry-run)+구성원별 결과·실패 재시도**, **액션형 대시보드**(조치 카드 + 좁은 화면 카드 레이아웃), 설정 인라인 검증(중복 ID·URL·폴더 겹침 경고).
- **운영 편의** — 설정 내보내기/가져오기(자격증명 제외), 종합 진단(서버·읽기/쓰기 권한·실시간), 모바일 절전(백그라운드 동기화 일시정지·대용량 파일 사전 검사), 삭제 정합 최대 건수 설정.

### 요구사항
- **Obsidian 1.11.4 이상** (데스크톱·모바일 모두 지원). Secret Storage API 사용으로 1.11.4가 필요합니다.
- **자가 호스팅 CouchDB** (시놀로지 NAS 등) — 필수 중앙 서버. [설정 방법](server/README.ko.md#couchdb-필수).
- **Yjs WebSocket 서버** — 실시간 공동 편집을 쓸 때만 선택. 공동 공간별 HMAC 토큰(`YJS_SECRET`) 권장 ([설정](server/README.ko.md#yjs-실시간-서버-선택), 구동 파일은 [`server/yjs/`](server/yjs/)).
- **Excalidraw 플러그인** — Excalidraw 그림 실시간 공동 편집을 쓸 때만 선택(미설치 시 해당 기능만 자동 비활성).

## 설치

### ① 커뮤니티 플러그인 (심사 통과 후)
설정 → 커뮤니티 플러그인 → 탐색에서 **CoVault** 검색 후 설치·활성화.

### ② 수동 설치 (릴리스 자산)
[Releases](https://github.com/wakeyi-git/obsidian-covault/releases)에서 최신 버전의
**`main.js` · `manifest.json` · `styles.css`** 를 받아 vault의 `<vault>/.obsidian/plugins/covault/` 에 넣고 활성화합니다.

### ③ BRAT (베타 테스트)
[BRAT](https://github.com/TfTHacker/obsidian42-brat) 플러그인에서 `wakeyi-git/obsidian-covault` 저장소를 추가합니다.

### 개발 빌드
```bash
git clone https://github.com/wakeyi-git/obsidian-covault.git
cd obsidian-covault
npm install
npm run build      # main.js 생성 (개발 중에는 npm run dev 로 watch)
```
산출물 세 파일을 위 ② 경로에 복사합니다.

> **모바일(iOS/Android)**: 같은 세 파일을 폰 vault의 같은 경로에 넣습니다. iCloud로 동기화되는
> vault라면 데스크톱에서 복사한 파일이 폰에 따라옵니다. 적용 후 Obsidian 앱을 완전히 종료했다 다시 엽니다.

## 서버 준비

CoVault는 **독립적인 두 서버**를 씁니다 — **CouchDB**(파일 동기화, 필수)와 **Yjs WebSocket 서버**(실시간 공동 편집,
선택). 두 서버는 **서로 통신하지 않으며**(플러그인이 둘의 유일한 클라이언트), 한 서버에 함께 두거나 완전히 다른 제공자에
나눠 둘 수 있습니다. 유일한 필수 조건은 **모든 클라이언트(운영자 + 모든 구성원)가 각각에 HTTPS/WSS로 닿을 수 있어야** 한다는
것입니다.

자세한 구축 방법은 **[`server/README.ko.md`](server/README.ko.md)** 에 있습니다 — Docker 명령, 호스팅 선택지
(NAS / 라즈베리파이 / VPS / PaaS / Cloudant), 구조와 제약, 실시간 서버 보안(리버스 프록시 `wss://`, `YJS_SECRET`,
접근 로그 마스킹). 실시간 서버 구동 파일은 [`server/yjs/`](server/yjs/)에 있습니다.

## 사용

최초 실행 시 역할 선택 화면이 뜹니다. 역할은 한 번 선택하면 잠기며, 변경하려면 설정의 '역할 재설정'을 사용합니다.

### 운영자 (Manager Mode)
1. 설정 → **관리자 계정**(CouchDB URL / admin 사용자·비밀번호) 입력 — 이 기기에만 저장됩니다.
2. **개별 공간**에서 `+ 구성원 추가`(또는 `명단 붙여넣기`로 일괄 — 줄마다 `이름,ID,폴더`이며 ID·폴더는 생략 가능, 기본 폴더도 지정 가능) → 이름·구성원 ID 입력 (Mirror DB/폴더는 비우면 자동).
3. 구성원 카드의 **초대** 클릭(또는 **일괄 초대**로 미초대 구성원을 한 번에 프로비저닝) → 플러그인이 구성원 계정/DB/권한을 자동 생성하고 **QR + 초대 코드**를 표시.
4. **연결 테스트**로 모든 구성원 DB 접근을 확인, **설정 적용**으로 동기화 시작.

> 운영자는 패널의 **‘시작하기’ 탭(온보딩 마법사)** 으로 서버 연결 → 워크스페이스 정보 → 구성원 등록 → 초대 → 첫 동기화를 순서대로 따라갈 수 있습니다.

### 구성원 (Member Mode)
- 운영자가 준 **QR을 휴대폰 기본 카메라로 스캔** → Obsidian이 열리며 자동 설정, 또는
- **초대 코드를 붙여넣기**(첫 실행 화면 또는 구성원 설정).
- 구성원은 자기 mirror DB에만 접근하는 전용 계정으로 연결됩니다.

### 명령 (`Cmd/Ctrl+P` → `CoVault:`)
**🎓 리본** 하나로 통합 패널을 열고, 아래 명령은 특정 탭/동작으로 바로 갑니다.

| 명령 | 동작 |
|---|---|
| 패널 열기 / 대시보드 열기 | 패널 열기. ‘대시보드 열기’는 학급 **대시보드** 탭으로 이동 |
| 전체 동기화 / 업로드만 / 다운로드만 | 수동 정합 (운영자는 전체 구성원) |
| 연결/권한 테스트 | CouchDB 연결·권한 확인 |
| 종합 진단 실행 | 서버 도달 + DB 읽기/쓰기 권한 + 실시간 상태를 한 번에 점검 |
| 피드백 추가 / 피드백 패널 열기 | 선택 영역에 앵커 댓글, 패널에서 목록·이동·해결 |
| 자동 동기화 켜기/끄기 | 실시간 감시·구독 토글 |
| 로컬 캐시 초기화 | 로컬 PouchDB 삭제 후 서버에서 다시 받기 |
| 충돌 목록 열기 | 충돌 비교/해소 (로컬 유지·원격 적용·두 버전 보관) |
| 동기화 상태 열기 | 구성원별 동기화 상태 표 — **관리 도구**(연결 테스트·진단·실시간 점검·캐시 초기화·서버 초기화/공유 새로고침)도 여기에 통합 |
| 구성원에게 복사 (배포 탭 열기) | 배포 탭에서 경로(파일/폴더) 선택 후 구성원에게 배포 — `{{memberName}}` 등 변수 치환 |
| 실시간 상태 확인 / 버전 히스토리 열기 | 실시간 진단 · 노트별 버전 스냅샷 |
| 로그 패널 열기 | 동기화 로그 보기 |

삭제한 파일은 **보관 폴더(`_삭제됨/`, 설정 가능)** 로 이동하며, 그 폴더에서 지우면 DB에서도 영구 삭제됩니다.

### 충돌
양쪽이 같은 파일을 다르게 편집하면 로컬을 보존(preserve-local)하고 원격 버전을 **`_충돌/` 폴더**에
꺼내 둡니다. `충돌 목록 열기`에서 비교 후 *로컬 유지 / 원격 적용 / 두 버전 보관*으로 해소합니다.
상대가 먼저 해소해 내 편집이 덮일 경우, 내 버전은 `_충돌/<파일>.내편집.md`로 보존됩니다.

### 첨부파일
이미지·PDF 등 비markdown 파일도 동기화됩니다(CouchDB attachment). 설정에서 *첨부파일 동기화* 토글과
*첨부 최대 크기(MB)* 로 제어합니다(모바일 보호). 첨부 충돌도 충돌 목록에 표시되며 로컬 유지·원격 적용·두 버전
보관으로 해소할 수 있습니다. 이미지·PDF 자체의 내용 diff는 없지만 파일명·크기·MIME을 표시하고 원격 사본은 `_충돌/`에 보존합니다.

### 운영자 배포
`템플릿/` 등 구성원 폴더 밖에 원본을 두고, **배포 탭**에서 경로를 골라(빠른 버튼: 현재 파일/현재 폴더, 대상 경로는
비우면 원본 이름) 선택·전체 구성원에게 배포합니다. **미리보기(dry-run)** 로 구성원별 대상·동작을 먼저 확인하고,
실행 후 구성원별 결과(작성/건너뜀/실패)와 **실패만 재시도**가 패널에 남습니다. `{{memberName}}` `{{memberId}}`
`{{workspaceId}}` `{{date}}` 변수가 구성원별로 치환되고, 기존 파일은 건너뛰기(기본)/덮어쓰기/새 이름 정책으로 처리합니다.

### 공동 폴더
운영자 설정의 *공동 공간*에서 모둠/워크스페이스 공간을 만들고 멤버 구성원을 고른 뒤 **배포**하면, 전용 DB(`share_*`)와
권한이 생성되고 구성원에게 자동 전파됩니다. 멤버 구성원 vault에 같은 폴더가 생겨 서로의 파일을 보고 편집합니다.
개인 미러와 겹치지 않도록 공동 폴더는 개인 동기화에서 자동 제외됩니다. 같은 파일 동시 편집은 충돌 UI로 해소합니다.
공동 공간 카드에는 운영 배지(미배포/배포됨/멤버 변경됨-재배포 필요)가 표시됩니다.

### 실시간 공동 편집
> **선택(고급) 기능.** CoVault의 핵심은 CouchDB **파일 동기화**이며 실시간 없이도 완전히 동작합니다.
> **먼저 파일 동기화를 성공시킨 뒤** 필요할 때 켜세요.

공동 폴더 문서를 글자 단위로 동시에 편집합니다(Yjs). 파일 동기화(CouchDB)와 **독립된 별도의 Yjs WebSocket
서버**가 필요합니다. 운영자가 설정에 서버 URL과 공간 시크릿을 입력하고 공동 공간을 배포하면 구성원에게 자동
전파됩니다. 공동 폴더 문서를 편집 모드로 열면 실시간 세션이 연결되고, 서로의 커서·이름이 표시됩니다. 편집
중에는 Yjs가 권위이며, 문서를 닫을 때 스냅샷이 CouchDB로 저장되어 오프라인 멤버에게 반영됩니다. 세션 도중
나중에 문서를 연 사람도 즉시 최신 공유 내용을 받습니다. 설정에서 **세션 중 스냅샷 주기(초)** 를 켜면, 편집을
닫기 전에도 일정 주기로 CouchDB에 본문이 저장되어 비실시간/오프라인 멤버가 더 빨리 최신본을 받습니다(리더
1인만 기록해 충돌 방지). 편집 영역 우하단에 **참가자 칩**(이름 + 색)이 상시 표시되어 마우스를 쓰지 않는
태블릿·모바일에서도 누가 함께 편집 중인지 보입니다(마크다운·Excalidraw 동일). 터치 기기에서는 더블탭으로
텍스트를 입력할 수 있고, 손가락으로 스와이프하면 포인터가 즉시 따라갑니다.

**실시간 제어·접근(실시간 탭).** 운영자는 **실시간 탭**에서 라이브 편집을 제어합니다: 사용 토글과 **세션 중 스냅샷
주기**가 상단에 묶이고, 그 아래에 선택형 **공유 파일 읽기 전용** 정책과 **활성 세션 목록**이 있습니다. 읽기 전용을 켜면
구성원은 공유 노트를 마음대로 편집하지 못하고, 그 노트가 **그 구성원에게** 활성 실시간 세션일 때만 편집이 열립니다.
공동 편집자는 **파일별로** 고릅니다 — 노트를 열면 강조된 세션 카드에서 참여 구성원을 선택합니다(기본값은 읽기 전용
정책에 따라 — 켜져 있으면 *아무도*, 꺼져 있으면 *전원*). 선택한 구성원만 라이브 세션에 참여하고 나머지는 일반 파일
동기화로 편집합니다. 각 카드는 함께 편집하는 사람을 **이름으로** 보여주고, 지정 파일은 닫아도 목록에 남아 클릭 한 번에
다시 열 수 있습니다. 구성원을 파일에서 빼면 **그 구성원의 라이브 세션이 즉시 종료**되고(읽기 전용 정책이면 노트가 다시
잠김), Excalidraw 그림도 같은 방식(뷰 모드)으로 잠기고 풀립니다. 문제 해결 동작(토큰 재발급·재배포, 실시간 상태 점검)은
탭의 별도 섹션에 있습니다. 구성원에게는 자신이 지정된 세션만 보이는 간소한 실시간 탭이 표시됩니다.

Yjs 서버를 띄우는 방법은 **[`server/README.ko.md` → Yjs 실시간 서버](server/README.ko.md#yjs-실시간-서버-선택)**(구동 파일은 [`server/yjs/`](server/yjs/))를 참고하세요.

**실시간 토큰 보안** — 서버에 `YJS_SECRET`을 설정하고 플러그인 설정의 **'Yjs 공간 시크릿(HMAC)'** 에 같은 값을
넣으면, 운영자가 공간을 배포할 때마다 **공동 공간별 서명 토큰**이 발급되어 구성원에게 전달됩니다. 토큰 payload에
`workspaceId`·`spaceId`(+선택 만료)가 들어가고 서버가 접속 room이 `<workspaceId>/share/<spaceId>/`로 시작하는지 검증하므로,
한 토큰이 유출돼도 **그 공간 room에만** 접근할 수 있습니다(워크스페이스 전체 X). 시크릿/멤버 변경 시 재배포로 토큰이
갱신되고, **'공간 토큰 만료(일)'** 로 TTL을 둘 수 있습니다. 운영자의 토큰·시크릿은 Obsidian Secret Storage에
저장됩니다. 실시간 인증은 **HMAC 전용** 이며, 모든 토큰은 단일 공동 공간 범위로 제한됩니다.

**Excalidraw 그림**도 공동 폴더에서 **요소 단위 실시간 공동 편집**을 지원합니다(추가·이동·삭제, 이름·색 커서, 이미지 동기화).
[Excalidraw 플러그인](https://github.com/zsviczian/obsidian-excalidraw-plugin)이 설치돼 있어야 하며(미설치 시 자동 비활성),
바인딩은 [`y-excalidraw`](https://github.com/RahulBadenkal/y-excalidraw)(MIT)를 사용합니다. 각자 줌/스크롤은 독립적이고
도형·커서는 씬 좌표로 공유됩니다. 실시간은 **`.excalidraw.md` 형식만** 지원합니다(세션 종료 스냅샷이 CouchDB로 전파되려면
마크다운 경로가 필요 — 순수 `.excalidraw`는 자동 비활성 + 안내).

### 피드백 레이어
본문을 직접 수정하지 않고 의견을 남기는 **앵커 기반 댓글**입니다(기술문서 §19.5). 노트에서 텍스트를 선택하고
"피드백 추가"를 실행하면 인용구·위치가 함께 저장되어, **피드백 패널**에 목록으로 표시되고 클릭하면 해당 위치로
이동합니다. 해결/삭제도 가능합니다. 패널의 **‘전체 미해결 보기’** 토글로 모든 노트의 미해결 피드백을 한 번에
볼 수 있습니다(구성원·노트 라벨 + 위치로 이동). 피드백 문서는 대상 노트가 속한 DB(개인 미러 또는 공유)에 저장되어
기존 동기화로 전파되며, 파일이 아니라 메타데이터이므로 vault에는 쓰이지 않습니다. 공동 폴더 문서와 일반 구성원
미러 노트 모두에서 동작합니다.

### 메신저(대화)
**대화** 탭은 운영자와 각 구성원 사이의 **학급 전체 채널**과 **1:1 DM**을 제공합니다. 학급 채널은 **학급(homeroom)**
공유 DB를 타므로 학급 공동 공간이 필요하고, DM은 각 구성원의 **개인 mirror DB**를 탑니다. 일반 텍스트 외에 **`[[위키링크]]`**
(`[[` 입력 시 옵시디언식 파일 자동완성), **URL**, **파일·이미지 첨부**를 보낼 수 있습니다 — 첨부 파일은 채널 첨부 폴더로
복사되어 상대가 실제로 받게 되고, 링크·이미지 미리보기는 인라인으로 렌더됩니다(클릭하면 열림). 메시지에는 작성자 표시
**이름**이 담겨 모두가 구성원 ID가 아니라 이름으로 봅니다.

### 학급 대시보드
> **선택 기능.** 운영자↔구성원 동기화를 가벼운 학급 작업 공간으로 확장합니다. 파일 동기화만 필요하면 건너뛰세요.

공동 공간 하나를 **학급(homeroom)** 으로 지정하면(설정 → 공동 공간 → "학급으로 지정") 전원에게 자동 프로비저닝되어
**대시보드** 탭을 구동합니다(🎓 리본으로 열기). 콘텐츠는 학급 폴더 아래 일반 마크다운 파일로 존재하고, 경량 상태(읽음
확인·제출·성적·체크)는 DB에 담겨 함께 동기화됩니다. 모듈:

- **알림장** — **옵시디언 편집창에서** 작성합니다: ‘새 알림장’이 템플릿으로 프론트매터가 든 초안 노트를 만들어 열고,
  내용을 채운 뒤 **게시**합니다(`published` 속성/버튼 — 구성원은 게시된 것만 봄). 구성원은 읽음 확인과 **댓글**(학급
  공개) 또는 **질문**(운영자에게만 비공개)을 남기고, 운영자는 인라인으로 답글을 답니다. 카드에서 편집(노트 열기)·삭제.
- **수업 안내 & 시간표** — **주간 시간표 그리드**, 각 칸에 **수업** 노트를 연결(알림장과 같은 편집창+프론트매터 방식),
  주/일 단위로 이동.
- **과제** — 대화상자에서 생성(제목·마감·배점·**공개 범위: 구성원별 비공개 또는 학급 공유**·대상 구성원·**루브릭**·템플릿).
  생성 시 각 대상에게 작업 파일(개인 미러 또는 공유 폴더)과 상태 문서를 **배포**합니다. 구성원이 **제출**(버전 스냅샷
  생성)하면 운영자가 **채점**(점수/루브릭/총평)하고 **반환**합니다. 과제는 **편집**(재배포, 제출·성적 보존)·**삭제** 가능.
- **체크리스트 / 루틴** — 매일/매주 체크 항목. 구성원이 체크하면 운영자가 구성원별 완료율을 봅니다(드래그로 순서 변경).
- **통계** — 알림장/수업 읽음, 과제 제출, 평균 점수, 체크리스트 완료율의 구성원별 비율을 **CSV로 내보내기** 가능.

**콘텐츠 템플릿** — 설정 → *콘텐츠 템플릿* 에서 유형별(알림장/수업/과제) 템플릿 파일을 지정하거나 비워서 내장 기본을
사용합니다. "기본 템플릿 만들기"로 시작 템플릿을 vault에 만들어 자유롭게 수정할 수 있습니다.

**동기화 구조 (오프라인 우선)**
```
Vault  ◄──(LocalWatcher / LocalApplier)──►  로컬 PouchDB  ◄──(live sync, retry)──►  원격 CouchDB
```
운영자는 구성원마다 `MirrorSync`를 하나씩 두어 여러 구성원을 동시에 동기화합니다.

## 보안 메모

- **초대 코드**에는 구성원 전용 비밀번호가 포함됩니다(조직 1회 온보딩용, base64 인코딩). 자체 만료는 없지만,
  유출이 의심되면 운영자가 구성원 카드의 **'비밀번호 재발급'** 으로 비밀번호를 회전해 **이전 초대를 즉시 무효화**합니다.
- **실시간 토큰**은 공동 공간별 **HMAC 서명 토큰**으로 발급되어, 유출돼도 해당 공간 room에만 접근됩니다
  (`workspaceId`·`spaceId` 바인딩 + 선택 만료). 서버는 `CHANGE_ME` 같은 placeholder/너무 짧은 시크릿이면 기동을 거부하고,
  토큰은 WSS로 전송되므로 전송 중 노출이 없습니다(서버/프록시 로그의 `?token=` 쿼리 마스킹은 [`server/README.ko.md`](server/README.ko.md) 참고).
- **Yjs 공간 시크릿**(운영자)과 **CouchDB 관리자 비밀번호**는 **Obsidian Secret Storage**(vault별 보관소)에 저장되어 `data.json`에 평문으로 남지 않습니다.
- **설정 내보내기**는 자격증명을 제외합니다 — 관리자 비밀번호, 구성원 비밀번호, `yjsSecret`, 공간 토큰, 기기 고유값.
- 운영자 관리자 자격증명은 운영자 기기에만 저장되며, 구성원은 admin 권한을 일절 다루지 않습니다.
- 구성원 간 데이터는 CouchDB `_security`로 서버에서 격리됩니다(다른 구성원 DB 접근 시 403).
- **오프라인 삭제 정합**은 기기별 manifest 기준선(내용 검증 + rev/hash 비교)과 **대량 삭제 임계치**로, 폴더 오설정 시
  대량 tombstone 사고를 막습니다. `localRoot`가 바뀌면 기준선이 무효화되어 삭제 정합을 건너뜁니다.
